# Life Stories - A Calm RPG

A peaceful, story-driven 2D life simulation RPG where you explore a village, meet NPCs, and experience a calm narrative.

## Installation & Setup

### Step 1: Install Python
Download Python 3.9 or higher from https://www.python.org/

### Step 2: Install Pygame
Open your terminal/command prompt and run:
```
pip install pygame
```

### Step 3: Run the Game
Navigate to the `game` folder and run:
```
python main.py
```

## How to Play

- **Use WASD or Arrow Keys** to move your character around
- Explore the village
- (More features coming soon!)
